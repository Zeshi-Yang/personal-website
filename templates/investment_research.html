Applied Research & Automation Projects

Originally conceived as exploratory prototypes during graduate school, these initiatives have evolved into production-grade tools aligned with professional investment workflows.

  • Multi-Factor Stock Screener
    Integrates Refinitiv fundamentals with sector-specific factor weightings and automated ranking logic; produces dynamic shortlists for fundamental deep dives.

  • Agentic Company-Analysis Workflow
    End-to-end pipeline that converts filings, analysis reports, and transcripts into Markdown, then employs specialised LLM agents for summarisation, thematic analysis, narrative synthesis, and investment-grade Q&A.

  • Real-Time News Intelligence Engine
    Combines sentiment scoring, and LLM-based ranking to surface actionable headlines for portfolio names.

  • Interactive Macro Dashboard
    Built in Python Dash; visualises key macroeconomic indicators with country and time-series filters, providing top-down context for allocation decisions.

  • Systematic Trading-Signal Framework
    Sandbox for rule-based alpha generation and execution logic, evolving from hobby projects.

  • Supporting Utilities
    Custom web-scraping pipelines and a secure account-tracking module that automate data collection and personal P&L monitoring.

Together, these solutions demonstrate a progression from hobbyist code to institutional-grade research infrastructure, uniting my engineering rigour with capital-markets insight.
